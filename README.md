## Descripción
En esta práctica se realiza el preprocesamiento de datos utilizando Python y diferentes librerías para analizar, limpiar y transformar datasets.

## Actividades realizadas
1. Identificación de instancias, atributos, features y labels.
2. Clasificación de variables.
3. Normalización Min-Max con NumPy.
4. Estandarización Z-Score.
5. Análisis de valores atípicos (outliers).
6. Exploración del dataset Palmer Penguins.
7. Aplicación de MinMaxScaler, StandardScaler y RobustScaler.

## Librerías utilizadas
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Resultados
Se aplicaron diferentes técnicas de escalado y se analizaron sus resultados mediante tablas y gráficas.

## Conclusión
En esta práctica aprendí la importancia del preprocesamiento de datos y cómo aplicar diferentes técnicas de escalado para preparar la información antes de utilizarla en modelos de inteligencia artificial.
